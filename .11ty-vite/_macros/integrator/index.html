Before you begin, you'll need an Okta Integrator Free Plan account. To get one, sign up for an [Integrator account](https://developer.okta.com/login). Once you have an account, sign in to your [Integrator account](https://developer.okta.com/login). Next, in the Admin Console: 1. Go to **Applications** > **Applications** 2. Click **Create App Integration** 3. Select **OIDC - OpenID Connect** as the sign-in method 4. Select ** Application** as the application type, then click **Next** 5. Enter an app integration name
Where are my new app's credentials? Creating an OIDC App manually in the Admin Console configures your Okta Org with the application settings. **NOTE**: You can also use the [Okta CLI Client](https://github.com/okta/okta-cli-client) or [Okta PowerShell Module](https://github.com/okta/okta-powershell-cli) to automate this process. See [this guide]( https://developer.okta.com/docs/guides/sign-into--app/-/create-okta-application/) for more information about setting up your app.
